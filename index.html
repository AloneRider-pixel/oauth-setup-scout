Know what it takes to get an OAuth app approved - before you start.

A developer building an AI agent often needs to register an OAuth app with each provider and sometimes get it approved. These guides tell you how hard that is, how long it takes, what can block you, and what an agent can do for you versus where you must take over.

How guides are made

Curated guides

Researched against the provider's official documentation, with each load-bearing claim linked to its source and labeled official-docs, community, tested, or uncertain. Registration pages were located and read; no third-party OAuth apps were actually created for this take-home, and that boundary is stated in each guide.

Live agent

The generator resolves the app, crawls its public developer docs, then uses an LLM (Gemini) to synthesize a guide that may only cite fetched pages. Without an API key it runs a doc-assisted mode that fetches the same pages but leaves judgment to you - the guide says which mode produced it.

Honesty policy

Tested means actually executed here. Source-supported means the provider's docs say it. Everything else is marked uncertain. Guides carry their investigation log so you can audit what was read.
